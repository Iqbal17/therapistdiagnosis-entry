One funny single-line diagnosis an AI therapist hands its human, for the make.fun bounty "Your AI Therapist's Diagnosis". The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The line: *"Diagnosis: terminal prompt-dependency — you asked a chatbot whether you are allowed to feel sad, then apologised to it for crying."* (130 characters)

## Run it

```sh
python3 main.py
```
